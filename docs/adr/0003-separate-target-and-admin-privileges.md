# 容器用户可以使用 sudo

只有一名实际操作者。日常 shell 使用与宿主同名、同 UID/GID 的普通用户，该用户属于容器的 `sudo` 组，密码与当前宿主账号一致。

`init` 以 root 读取同名宿主用户的密码哈希，写入本次运行代的 root-only 文件。容器启动时用该哈希设置容器用户密码；明文密码不进入仓库、镜像、配置或日志。迁移到其他主机后重新执行 `init`，就使用新主机上的账号密码。宿主密码发生变化后也要重新执行 `init` 并重建容器。

为了让 setuid `sudo` 生效，目标容器不设置 `no-new-privileges`，也不丢弃 Docker 默认的全部 capability。这个权限只在目标容器内生效：目标容器仍不挂载 Docker socket、宿主审计目录或宿主网络命名空间，外部网络策略和审计路径不变。宿主上的 `root-shell` 保留为容器内 sudo 无法使用时的恢复入口。
