# 请求审计不能阻塞正常响应

默认同时保存目标、DNS 和网关网络命名空间中的全部数据包、目标 cgroup 的连接记录，以及透明代理能解密的普通 HTTP/TLS 请求。响应正文不作为放行前提：网关收到响应头后立即逐块转发，只记录响应头、状态、声明长度和传输错误，不等待完整响应落盘。审计覆盖整套受控开发机，但不能采集同机其他用户的通信。

分析指定软件时，每条连接必须能归属到进程，并尽量完整还原软件发出的请求。应用再次加密时，还要针对该实现增加加密前的捕获。严格模式可以在请求发往上游前审核；日常模式中的普通公网 HTTP/HTTPS 不逐条等待审核。响应正文需要专项分析时另行捕获，不能让通用网关为了审计而缓存或改写响应。
