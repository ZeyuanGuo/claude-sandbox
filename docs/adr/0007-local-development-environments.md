# 开发环境由每台服务器本地提供

开发环境由每台服务器自己负责。平台不发布、重建或比较其中的包版本。

大型环境目录按本机 `host.yaml` 显式挂载，并尽量保持容器内外路径一致；环境不复制进镜像、控制仓库或发布包。`profile.default_conda_env` 只选择本机进入 Shell 后默认激活的 Conda 环境，通用代码不写死环境名。

主机可以把 Conda 根目录同路径读写挂载，并选择一个默认环境。这允许容器修改宿主环境，是部署者明确接受的取舍；其他服务器可以选择不同环境、改为只读或不挂载。验收必须检查实际 Python 路径、关键包导入和 GPU 计算，不能只检查环境名。
