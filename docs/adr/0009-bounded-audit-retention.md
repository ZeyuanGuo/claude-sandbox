# 审计数据采用分级保留与硬容量上限

完整 PCAP 和明文默认保留 72 小时；DNS、连接、进程和策略日志保留 30 天。PCAP 的 100 GiB 上限是所有运行和所有抓包点的合计，明文初始上限为 50 GiB，结构化记录初始上限为 10 GiB。长期 PCAP 另按主机配置使用有界循环文件，避免单次运行无限增长。达到任一上限时先停止联网，不能为了继续运行而提前删除未到期证据。明文只允许操作者从宿主侧提权读取。

已结束运行且超过保留期的本项目 PCAP、明文归档和结构化记录由 `storage rotate` 定时删除；当前运行、活动明文流、异常命名对象和共享 Docker 数据不在自动范围内。长期案例必须手动归档，并记录配置、时间范围、SHA-256 和可见范围。大文件写入主机配置指定的大容量目录，不能挤满根分区。审计分区默认保留 `max(200 GiB, 容量的 10%)`；主机可提高这些限制，不能在没有重新验收的情况下调低。
