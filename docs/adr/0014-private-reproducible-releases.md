# 私有发布控制代码、镜像、策略和文档

控制代码、文档和策略放在独立的私有 Git 仓库中，并固定 Git commit。基础镜像固定上游 digest；目标和网关镜像使用各自构建输入摘要作为标签，并在镜像标签中保存完整摘要。构建后把实际 Docker image ID 写入 root-only 构建记录，启动时同时核对输入摘要和 image ID。每次发布记录 Git commit、构建输入摘要、Docker 内容摘要、策略版本、工具版本和验收方法，不使用会变化的 `latest` 或共享 `:dev`。

新主机可以从固定源码本地构建。私有 GHCR 可以缓存并分发已经验收的镜像，但不是复现的前置条件；若使用 registry，仍必须按内容 digest 拉取并核对镜像内的构建摘要。

本地项目、开发环境、数据、checkpoint、上游凭据和普通日志不打包发布。只有手动归档的分析案例可以作为受限证据保存。
