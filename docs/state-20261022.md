## 部署原则（论文完成前）

1. **其他机器不要启动 `claude`、不要 `/login`**：同一账号在多设备/多出口登录会提高风控风险；论文完成后再逐台验证设备指纹与出口。
2. 需要验证配置时只启动沙盒服务与 `sbc status`，不进入 `sbc claude`。
3. 所有用户可写、需要跨机一致的沙盒状态放在共享 Home 内（当前是 `.claude`）；控制面与审计留在 Home 外是控制器的硬约束（`share_host_home` 时 `state`/`audit` 必须在 Home 外），且必须 root-only。
4. 新增机器前先确认：`entry.json` 存在、控制器 release 与 4090-48 一致、镜像 tag 一致、策略 digest 一致、`host.yaml` 的 `mounts` 与 48 对齐。
